# Arduino Traffic Light

## Bill of Materials

| Quantity | Component |
|---:|---|
| 1 | Arduino Mega 2560 |
| 1 | Standard-size breadboard |
| 1 | Red LED |
| 1 | Yellow LED |
| 1 | Green LED |
| 3 | 220 Ω resistors |
| 7 | Breadboard jumper wires |
